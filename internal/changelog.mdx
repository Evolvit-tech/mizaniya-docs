<Update label="13–15 Nov 2026" description="Money flow, V-TPE switch, staging on Docker">
  **Money flow and wallets**

  - Each sale's margin is split into admin profit and POS reserve. POS [`2a07667`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/2a07667), shared DB [`03ecea4`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Shared-Database/commit/03ecea4)
  - The admin's three wallets, with tabs for balance, admin profit and POS profit. Admin API [`8a67eef`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/8a67eef), admin web [`9f6cc72`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market-admin/commit/9f6cc72)
  - Withdrawals are held until the master confirms receipt; partial sends and not-received reports. POS [`6ccf501`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/6ccf501), market [`14f30e1`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/14f30e1)
  - Direct admin top-ups are flagged for their receiver. Admin API [`ca56129`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/ca56129), market [`d6fe1b2`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/d6fe1b2)

  **V-TPE switch**

  - `VTPE_ENABLED` turns customer QR payment off for gift cards, bills and eSIM; cash stays. POS [`be68de3`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/be68de3), market `VITE_VTPE_ENABLED` [`82943b8`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/82943b8)

  **Gift cards and eSIM**

  - Gift cards of every region are sold; one tile per brand, region picked on the card. POS [`c525b52`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/c525b52), market [`2d17442`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/2d17442)
  - The eSIM refund request is removed. POS [`fb43133`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/fb43133)
  - eSIM sales appear in the transaction history. POS [`65e8666`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/65e8666), market [`4b02d4f`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/4b02d4f)

  **Staging and tooling**

  - Staging runs on Docker images from GHCR, deployed over SSH, one deploy at a time. POS [`681ad5a`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/681ad5a), [`f6b8420`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/f6b8420)
  - `MAIL_DISABLED` and `SMS_DISABLED` for a staging without providers. POS [`4dc8571`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/4dc8571)
  - The admin email code is `000000` outside production. Admin API [`482335f`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/482335f)
  - Export button at the top of every page, and quick date ranges. Market [`2c2c3f0`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/2c2c3f0), core [`140565b`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market-core/commit/140565b)
</Update>

<Update label="10–12 Nov 2026" description="Network pricing, partner API reference">
  **Network pricing for gift cards, eSIM and bills**

  - The admin sets a gift card price per top master; a master sets one per agent. POS [`28f8e4c`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/28f8e4c), [`9c67510`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/9c67510), admin API [`d70ee27`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/d70ee27)
  - eSIM cost-plus pricing per country and region. POS [`03625d6`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/03625d6), admin API [`be64ad8`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/be64ad8), shared DB [`0f37b3c`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Shared-Database/commit/0f37b3c)
  - Bill tariffs negotiated level by level. POS [`fe924f2`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/fe924f2), admin API [`3430c45`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/3430c45)
  - eSIM paid in cash or V-TPE from the POS balance. POS [`d475fa1`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/d475fa1)

  **Partner API**

  - Every partner route documents every response with examples; the reference is in the app's developer area. POS [`17316ed`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/17316ed), [`b3dc861`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/b3dc861), market [`f0932ba`](https://github.com/Evolvit-tech/mizaniya-pay-frontend-market/commit/f0932ba)
  - Bills can be paid through the partner API, behind `BILLS_ENABLED`. POS [`a4b0b86`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/a4b0b86)
  - Test and live keys side by side were tried, then reverted: one key type per deployment, set by `PARTNER_API_ENVIRONMENT`. POS [`062febd`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/062febd), revert [`a1fec2d`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/a1fec2d)

  **Fixes**

  - Commissions: the network is rescaled with the provider rate (rule 5). POS [`4d51180`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/4d51180), admin API [`3ac21c8`](https://github.com/Evolvit-tech/Mizaniya-Pay-Admin-POS-Backend/commit/3ac21c8)
  - The gift card catalog loads on start and refreshes when stale. POS [`ea196a6`](https://github.com/Evolvit-tech/Mizaniya-Pay-POS-Backend/commit/ea196a6)
</Update>
